# Archiv — überholte Implementierungs-Notizen

Diese Dateien sind **Historie der PHP-Entwicklung** und kein Pflicht-Lesestoff für neue Runtimes. Ihr Inhalt ist vollständig in die konsolidierte Spezifikation (`50-spezifikation/`, Stand v0.5/0.6) und in den `RUNTIME-LEITFADEN.md` eingeflossen.

- `SPEC-UPDATE-v0.3.md … v0.6.md` — Delta-Notizen, die der PHP-Agent mitten in der Arbeit brauchte („was hat sich seit deinem Stand geändert", nach JOB-IDs sortiert). Durch den konsolidierten Leitfaden ersetzt.
- `RUNTIME-PORTING.md` — frühere Kurzfassung des Porting-Briefings (Node); aufgegangen im `RUNTIME-LEITFADEN.md`.
- `AGENT-BRIEFING.md` — das **PHP-Einstiegs-Briefing** (vor Projektstart, Spec-Stand v0.2 / 17 Fixtures). Sein generischer Nachfolger ist der `RUNTIME-LEITFADEN.md`; archiviert 2026-06-20.
- `JOBS.md` — das **PHP-Backlog** (JOB-000…014, vollständig abgearbeitet). Die fortlebende Job-Reihenfolge ist im `RUNTIME-LEITFADEN.md` kondensiert; archiviert 2026-06-20.

Maßgeblich für eine neue Runtime: `../RUNTIME-LEITFADEN.md` + `50-spezifikation/` + `testing/testsuite/`.
